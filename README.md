# chalarince-pixel.github.io

Source code for Chala Rince's personal developer website and systems portfolio, hosted on GitHub Pages:
**[chalarince-pixel.github.io](https://chalarince-pixel.github.io)**

## Tech Stack
- **HTML5 & Vanilla JS** (Lucide Icons)
- **Tailwind CSS v4** (via browser runtime CDN)
- **Google Fonts** (Newsreader serif + JetBrains Mono + Plus Jakarta Sans)
- **Hosted on GitHub Pages** (zero build step required)

## Structure
- `index.html`: Main landing page with technical overview, systems engineering focus, and featured repositories.
- `projects.html`: Comprehensive architectural breakdown of CUDA Hopper kernels, TinyML microcontroller inference, and Neural Rendering.
