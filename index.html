Engineering Principles

01.
Respect the Hardware: Software abstractions shouldn't mask memory hierarchies. Peak throughput comes from aligning data paths to cache line widths, vector lanes, and tensor cores.
02.
Measure, Don't Guess: Profiling drives optimization. Performance claims must be verified via roofline models, cycle counters, NCU/Nsight metrics, and memory bandwidth utilization.
03.
Zero-Waste Architecture: From embedded SRAM to datacenter HBM3, memory allocation and kernel launches should have zero runtime fluff.
