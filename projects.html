MatMultOnHopperChala

High-Performance Hopper GEMM Optimization
View Repository

A systematic benchmark and progressive implementation of General Matrix Multiply (GEMM) kernels targeting the NVIDIA H100 GPU (sm_90). Compares cuBLAS throughput against custom CUDA kernels designed to leverage new architectural primitives.

Technical Architecture:
  • WGMMA (MMA Async): Asynchronous Warpgroup Matrix Multiply and Accumulate operating directly from Shared Memory without register pressure.
  • Tensor Memory Accelerator (TMA): 1D/2D asynchronous bulk memory transfers between global HBM3 and shared memory without warp stalls.
  • Distributed Shared Memory (DSM): Inter-SM cooperative clustering allowing SMs within a cluster to access peer shared memory.
  • cuBLAS Comparisons: Roofline and throughput analysis identifying bottle-neck transitions from memory-bound to compute-bound regimes.

McuDevAI

Edge AI Sandbox for ESP32-S3 (~110 µs Inference)
View Repository

A complete, end-to-end TinyML deployment pipeline executing on bare-metal ESP32-S3 microcontrollers under FreeRTOS. Bridges neural network training in PyTorch through ONNX export, post-training INT8 quantization, and C-array serialization into Flash memory.

Technical Architecture:
  • Silicon-Level Acceleration: Binds TensorFlow Lite Micro to Espressif’s esp-nn library, utilizing the ESP32-S3 128-bit vector coprocessor (PIE) for SIMD matrix math.
  • INT8 Calibration: 4x memory footprint reduction and fast integer arithmetic through representative dataset quantization.
  • Embedded Runtime: Lightweight 3 KB internal SRAM Tensor Arena with zero dynamic heap allocation during inference loops.
  • Real-Time ASCII Plotter: Serial UART telemetry rendering prediction curves tracking mathematical ground truth in ~110 µs.
ESP-IDF FreeRTOS TFLite Micro esp-nn PyTorch

NeuralRenderingMPSChala

NeRF & Stochastic Geometry SDF on Apple Silicon
View Repository

High-performance neural rendering and 3D surface reconstruction utilizing Apple Silicon Metal Performance Shaders (MPS). Implements neural implicit representations and fast geometry extraction algorithms.

Technical Architecture:
  • Sub-Second Geometry Extraction: 1-second cross-platform 3D triangular mesh extraction from continuous Signed Distance Fields.
  • Multi-View Human Head Reconstruction: Trained on the 38-camera dome Meta Multiface dataset to produce photorealistic geometry.
  • From-Scratch LoRA Adaptation: Low-Rank Adaptation applied directly into implicit rendering pipelines for parameter-efficient tuning.
  • MPS Acceleration: Custom shader graph execution optimized for unified memory unified GPU cores.
